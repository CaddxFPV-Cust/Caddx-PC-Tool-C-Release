# Caddx PC Tool

## 简介 / Introduction

**Caddx PC Tool** 是一款面向消费端用户的图传固件升级工具，用于对 Caddx Ascent 系列图传设备进行固件更新、版本升级和功能维护。

该工具可帮助用户将图传设备升级至最新固件版本，以获得更稳定的图传性能、更好的兼容性以及后续新增功能支持。

**Caddx PC Tool** is a consumer-facing firmware upgrade tool for Caddx Ascent series video transmission devices. It is used to update firmware, upgrade versions, and maintain supported Caddx Ascent series video transmission products.

This tool helps users upgrade their video transmission devices to the latest firmware version, providing more stable video transmission performance, better compatibility, and support for future features.

---

## 支持设备 / Supported Devices

本工具适用于以下 Caddx Ascent 系列产品：  
This tool is applicable to the following Caddx Ascent series products:

- Caddx Ascent Lite
- Caddx Ascent Lite +
- Caddx Ascent VRX 
- Caddx Ascent VRX Pro
- Caddx Ascent GM1 V2
- Caddx Ascent GM3 V2

---

## 主要功能 / Features

- 支持 Ascent 系列图传设备和 GM V2系列的固件升级  
- 支持识别已连接的图传设备  
- 支持选择本地固件文件进行升级  
- 提供升级进度显示  
- 提供升级结果提示  

Features:

- Supports firmware upgrade for Ascent series video transmission devices and GM V2 series devices  
- Supports detection of connected video transmission devices  
- Supports selecting local firmware files for upgrade  
- Provides upgrade progress display  
- Provides upgrade result notification

## 系统要求 / System Requirements

在使用本工具前，请确认您的设备满足以下要求：  
Before using this tool, please ensure that your device meets the following requirements:

- 操作系统：Windows 10 / Windows 11 或更高版本  
- USB 接口：USB 2.0 或更高版本  
- 建议使用原装或质量可靠的数据线  
- 确保设备供电稳定  

System requirements:

- OS: Windows 10 / Windows 11 or later  
- USB: USB 2.0 or higher  
- An original or high-quality USB cable is recommended  
- Ensure stable power supply for the device during the upgrade process

## 安装步骤 / Installation

1. 下载升级工具压缩包。  
2. 解压压缩包到本地目录。  
3. 双击运行升级工具主程序。  
4. 如系统提示权限，请允许程序运行。  

Installation steps:

1. Download the upgrade tool package.  
2. Extract the package to a local directory.  
3. Double-click the executable file to launch the tool.  
4. If prompted by the system, allow the program to run.
