
# Caddx PC Tool

## 简介 / Introduction

**Caddx Ascent Series Video Transmitter Upgrade Tool** 是一款面向消费端用户的图传固件升级工具，用于对 Caddx Ascent 系列图传设备进行固件更新、版本升级和功能维护。

该工具可帮助用户将图传设备升级至最新固件版本，以获得更稳定的图传性能、更好的兼容性以及后续新增功能支持。

**Caddx Ascent Series Video Transmitter Upgrade Tool** is a consumer-facing firmware upgrade utility for Caddx Ascent series video transmission devices. It allows users to update the firmware of supported Caddx Ascent products to improve stability, compatibility, and overall performance.

## 主要功能 / Features

- 支持 Ascent 系列图传设备和GM V2的固件升级  
- 支持识别已连接的图传设备  
- 支持选择本地固件文件进行升级  
- 提供升级进度显示  
- 提供升级结果提示  
- 适用于消费端用户，操作流程简单清晰  

Features:

- Firmware upgrade for supported Caddx Ascent series devices  
- Device detection and connection status display  
- Local firmware file selection  
- Upgrade progress indication  
- Upgrade result notification  
- Simple and user-friendly operation for consumer users

## 系统要求 / System Requirements

在使用本工具前，请确认您的设备满足以下要求：

- 操作系统：Windows 10 / Windows 11 或更高版本  
- USB 接口：USB 2.0 或更高版本  
- 建议使用原装或质量可靠的数据线  
- 确保图传设备供电稳定  

System requirements:

- OS: Windows 10 / Windows 11 or later  
- USB: USB 2.0 or higher  
- A reliable USB cable is recommended  
- Ensure stable power supply during the upgrade process

Installation steps:

1. Download the upgrade tool package.  
2. Extract the package to a local directory.  
3. Double-click the executable file to launch the tool.  
4. If prompted by the system, allow the program to run.
